Razer 무선 충전기 크로마 조명 — PC 프로그램

※ Razer 공식 프로그램이 아니라 개인이 만든 도구입니다.
   화면의 충전기 사진·아이콘·로고는 Razer의 자료입니다.


■ 실행
1. 압축을 먼저 풉니다. (압축 파일 안에서 바로 실행하면 안 됩니다)
2. 풀린 폴더 안의 RazerChargerChroma.exe 를 실행합니다.
   - 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누르세요.
3. 바탕화면 바로가기가 필요하면 "바탕화면 바로가기 만들기.bat" 을 실행하세요.

폴더 안의 파일은 모두 같이 있어야 합니다. exe 만 따로 옮기면 실행되지 않습니다.


■ 필요한 환경
- Windows 10 / 11 (64비트)
- Microsoft Edge WebView2 런타임
  Windows 11과 최신 Windows 10에는 이미 들어 있습니다.
  없다는 안내가 뜨면 Microsoft 사이트에서 "WebView2 런타임"을 설치한 뒤 다시 실행하세요.


■ 연결
- USB (권장)
  충전기 케이블을 PC USB 포트에 꽂으면 자동으로 잡힙니다.
  페어링이 필요 없고, 충전기에 지금 설정된 효과를 읽어 와 보여 줍니다.
- 블루투스
  USB로 연결되어 있지 않을 때 씁니다. 충전기는 기기 하나만 기억하므로,
  처음 한 번은 충전기 버튼을 5~6초 길게 눌러 페어링 모드로 만든 뒤
  "고급 → 블루투스 → 연결"을 누르세요. 이렇게 하면 폰과의 블루투스 연결은 끊어집니다.


■ 화면
- 첫 화면: 충전기 카드와 "충전 효과" 줄.
  줄을 누르면 색 편집, 오른쪽 스위치로 켜고 끄기, 오른쪽 아래 버튼은 고급 설정입니다.
- 색 편집: 색상환을 누르거나 끌어서 색 고르기, # 칸에 색 코드 입력,
  왼쪽 아래 ☀ = LED 밝기, 오른쪽 아래 버튼 = 효과(정적·브리딩·스펙트럼·웨이브).
  바꾸면 바로 충전기에 적용됩니다.
- 고급: 대기 효과(폰을 올려 두지 않았을 때 조명), 상태 표시기, 효과 타이머,
  연결 정보, 기기 설정 초기화, 통신 기록.


■ 알아 둘 것
- 절전: 대기 효과 타이머(기본 15분)가 지나 조명이 꺼지면 충전기가 잠들어
  USB 명령을 받지 않습니다. 화면에 "절전 중"이 뜨면 충전기 버튼을 누르거나
  폰을 올려 두세요. 그사이 바꾼 설정은 충전기가 깨어나면 적용됩니다.
- 상태 표시기·타이머·초기화는 블루투스로 연결했을 때만 바뀝니다.
- 설정과 통신 기록은 %LOCALAPPDATA%\RazerChargerChroma 에 저장됩니다.
  프로그램을 지우려면 이 폴더와 압축을 풀었던 폴더를 지우면 됩니다.
